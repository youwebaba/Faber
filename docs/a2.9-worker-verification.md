for an external action, then restores an older pre-effect runtime snapshot.
For a verified outcome, the worker reuses the later immutable receipt. For a
deliberately dropped acknowledgement after the destination write, it refuses
replay and requires review. Explicit operator reconciliation and Resume retain
exactly one destination line. These are actual filesystem effects; no mail was
sent and no paid API was called. Separate connector evidence covers Outlook.
An additional regression changes the model's proposed arguments after stale
restore: the new action waits for explicit, nonrememberable approval and denial
still leaves exactly one destination line. A malformed boot status is also
tested with an actual owned process; it opens paused with usable shutdown and
releases the kernel lock.

Portable restore requires reviewed current authority and explicit job binding.
Changing to a different connected account cannot redirect an old intent.
Newer local outputs and cursors survive, and an older archive does not replace
a newer local routine revision. Credential stores, authorization values,
headers, token fields and recognizable credentials are omitted from the
bounded archive. A same-profile independent watermark is required.
