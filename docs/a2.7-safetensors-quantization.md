# Safetensors quantization at load

SAFELOAD02 adds selectable CPU load profiles to the normal downloaded-model
picker. **Original · float32 CPU**, **4-bit · Q4_0** and **8-bit · Q8_0** use the
approved Mistral.rs 0.9.5 library, pinned to
`465191d0b0a7e2432d327b0de06204ab3f94d3a2`. Only Faber's narrow adapter changed;
the official engine and its dependency versions remain unchanged.

Select a complete supported original Safetensors text package, choose a load
profile and Start. Use in this chat remains explicit. Stop is required before
changing the loaded profile. Successful choices are saved per scanner-issued
model ID; a later default Start uses that model's last successful profile.
Changing a model's files changes its ID and requires a fresh selection.

`localModels.start` and the existing Computer-protected `local_model_start`
accept optional `quantization:{mode:'none'|'q4_0'|'q8_0'}`. The same validator
serves the UI and tools. GGUF and external Ollama requests reject this native
option explicitly. No published weight encoding, external endpoint or chat
selection changes implicitly.

The profile object is a strict, extensible version boundary for later native
intermediate/mixed modes. a2.7 does not accept arbitrary quantizer names,
topology files, custom code, executable flags or requested GPU placement.
Default context, CPU placement and the a2.6 architecture/checkpoint gates apply.
Prequantized Safetensors checkpoints still require a separately compatible route.

## Actual loading and ownership

The adapter applies official `TextModelBuilder.with_isq(IsqType::Q4_0)` or
`with_isq(IsqType::Q8_0)` before loading; original mode retains float32 CPU
execution. Quantization uses the selected immutable original weights and writes
no converted model files. Temporary hardlinks and copied checked support data
retain the a2.6 lifecycle and path checks. Stop removes them and the private key.

Original loading and quantization can require considerably more RAM than the
source download. Quantization adds startup time and temporary working buffers.
Output heads, embeddings, norms and shape-constrained tensors may use different
precision. The UI labels the requested encoding and loader acceptance; it does
not label every stored layer with that encoding or claim a measured memory fit,
speedup or unchanged generation quality.

Protocol 2 adds a bounded, strict JSON launch profile and requires the private
worker's ready frame to confirm that exact profile. A mismatch kills the child
before readiness or provider registration. The native process still has no
network listener or executable tool service. The authenticated Faber loopback
endpoint, browser-origin rejection, function-only tool DTOs, stream bounds and
cancel/reuse behavior are retained.

The adapter source and all immutable payload files are pinned in
[safetensors-runtime-lock.json](../build/safetensors-runtime-lock.json). The
reviewed executable is 65,885,696 bytes, SHA-256
`e27601011ddcbd0fb9dcc43d9d086788a65802449005c7b32998c7a3f781e809`.
Build instructions, official native compiler options, notices and full-byte
preparation/prepack/after-pack privacy gates remain in the
[a2.6 build guide](a2.6-safetensors.md). The adapter and compiled engine remain
outside self-upgrade authority. No native dependency or license changed.

## Acceptance

November 9, 2026, Windows x64. The exact newly pinned payload was exercised
through registered `local_models_list`, `local_model_start` and
`local_model_stop` tools against the public Apache-2.0 checkpoint
`HuggingFaceTB/SmolLM2-135M-Instruct` at
`12fd25f77366fa6b3b4b768ec3050bf629380bac`. Faber downloaded the complete
272,496,399-byte package through the ordinary pinned package path. Original
weights have SHA-256
`5af571cbf074e6d21a03528d2330792e532ca608f24ac70a143f6b369968ab8c`.

All three modes passed actual CPU completions, streaming, cancel followed by
another completion, saved-profile inspection and Stop. Each run verified original
weight hashes before and after; missing-key/browser-origin rejection; absent
upload/reload/UI/MCP routes; zero worker-owned listeners; closed host endpoint;
process exit; and staging/key removal. Tests used isolated temporary profiles,
public weights and no paid provider.

```powershell
$env:FABER_SAFETENSORS_MODEL_DIRECTORY = '<absolute complete public package directory>'
foreach ($mode in @('none', 'q4_0', 'q8_0')) {
  $env:FABER_SAFETENSORS_QUANTIZATION = $mode
  node test/safetensors-managed-live-smoke.mjs
  if ($LASTEXITCODE) { throw 'Native quantization acceptance failed' }
}
npm exec electron . -- --smoke-local-models
npm test
npm run smoke
```

The actual Electron picker separately passed Q4_0 selection, Start, explicit Use,
controlled chat completion, Stop and agent default Start restoring that profile.
Existing GGUF readiness, incompatible load and cancellation cases remained in the
same fixture. A unit check rejects an incorrect native quantization handshake;
tests also reject native options on GGUF/Ollama and unsupported profile fields.
Full tests and the general Electron bridge/renderer smoke passed. Native Rust
DTO tests and full executable/DLL/privacy/hash verification passed.

This establishes working load profiles and lifecycle behavior. Useful model tool
selection, model-wide precision guarantees, benchmark-quality RAM/speed/quality
comparisons, GPUs and clean-machine installer execution remain separate work.

## Downloaded GGUF discovery correction

An ordinary untracked main model nested under a repository directory containing
`-MTP-GGUF` was wrongly hidden by the shared auxiliary classifier. Classification
now examines filename tokens and explicit auxiliary directory names. Main files
remain discoverable from the configured library root; genuine `model-MTP`,
`mmproj`, adapter and explicit `mtp/` files remain excluded.

Regression checks cover root and revision-directory scans plus normal Hub
metadata/catalog callers. An actual existing root scan found the complete
549,698,976-byte `Qwen3.5-0.8B-Q4_K_M.gguf` beneath its MTP-named repository
available, without changing the configured folder to a revision directory.
