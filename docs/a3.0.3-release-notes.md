# Faber a3.0.3

Ask a chat or one of its agents to research a topic, or paste a list of public URLs to read. Faber starts a local MCP crawler when the run needs it, using the chat's existing Network permission. It works with local models and model connections that support tool calls. No additional setup or API key is required.

- **Find sources.** Keyword searches use Mwmbl, with Wiby as a fallback. Results include source URLs and identify the search provider. Direct URL reads go from the PC to the source.
- **Read many sites at once.** One job accepts up to 1,000 seed URLs, runs up to 16 concurrent page reads and can follow links within the supplied origins. Agents can inspect progress, failures and excerpts, or cancel an active job. The reader honors robots.txt and site rate limits.
- **Check the evidence.** Agents can search retained text for a phrase, open the matching passage, or continue reading a long page. Partial results and failed reads are labeled. Jobs belong to the requesting run.
- **Use the browser for actions.** For a sign-in, application or upload, the agent can open the source URL in the existing Chromium browser. The crawler uses public pages and keeps browser session cookies separate.
