## Deterministic validation

The focused regression command passes 56 tests:

```powershell
node --test test/hub-packages.test.mjs test/hub.test.mjs test/hub-quantizations.test.mjs test/ui-models.test.mjs test/ui-faber.test.mjs test/ui-local-models.test.mjs test/core-local-library.test.mjs test/core-local-details.test.mjs
```

Coverage includes authoritative index references, nested support data, missing
shards/configuration, traversal, incompatible component encoding, exact five-role
selection, re-inspection before approval, safe streaming publication/cancellation,
offline grouping and exclusion of Music3 from the chat picker. Long-running file
reservations reject overlapping downloads/deletion while allowing unrelated hub
requests to complete.

`npm run smoke:models` also passed with an isolated temporary profile and
controlled fetch. It exercises real renderer package controls and the registered
`hf_*` tools through core permission approval. Safetensors package selection
fetches configuration with weights; Music3 remains disabled until all five roles
have one selected variant, then downloads precisely those components and license.
Progress/speed, retained search/settings drafts, GUI/agent cancellation, disk
pipeline presentation and compact layouts pass. Local screenshots and the JSON
report remain outside distributable source.

## Limits

Safetensors package detection describes published data completeness, not loader
support. Model-specific custom code is never downloaded automatically or run.
Shared configuration/tokenizer/index data remains when recycling weights so that
another package is not broken. The native Music3 Safetensors package requires a
compatible Diffusers runtime; the bundled Music3 adapter uses five GGUF files.
No large weight download or music inference was needed for these package checks.
