# a2.6 document, vector and animation verification

DOC03, DOC04, VECTOR01, ANIM01 and MEDIA08 use the existing `media_show`
publication path, immutable chat-scoped copies, native Save As and authenticated
256 KiB remote chunks. [MEDIA.md](../MEDIA.md) describes the supported content,
including DOCX text reflow, labeled table cells and explicit skipped-content
markers. Saved highlights/notes belong to the document SHA-256 revision and
page, with a text offset that distinguishes repeated phrases.

## Isolation and limits

The renderer transfers only an owned attachment to a sandboxed frame on the
separate `faber-preview://viewer` origin. The frame has no preload, Node, Faber
bridge or parent DOM access. Its CSP permits no external network, objects or
nested frames. The host serves only a fixed static-file allowlist on that
origin; application paths and query-based path substitutions are rejected.
Annotation changes use explicit parent UI actions with ownership, revision,
cancellation and read-only rechecks. Idempotent note IDs survive acknowledgement
loss; remote changes use the existing mutation receipt path.

| Input | Enforced bounds |
| --- | --- |
| PDF / DOCX | 64 MiB compressed file |
| PDF | 2,000 pages; 50,000 text items / 2 million text characters per page; 8 million rendered pixels; 15 second load and 30 second render deadlines |
| DOCX ZIP | 512 entries, 32 MiB declared expanded aggregate, 8 MiB per entry, 200:1 expansion ratio; only `word/document.xml` is inflated |
| DOCX text | No DTD/entities; 100,000 XML node delimiters, 10,000 paragraphs, 50,000 runs, 2 million text characters, 500 reflow pages |
| SVG | 4 MiB, 20,000 elements, 8 million pixels; image-only sanitized snapshot with external/active content and CSS removed |
| GIF / APNG | 16 MiB, 500 frames, 8 million pixels per frame, 32 million frame pixels in aggregate; each drawn VideoFrame is closed |
| Annotations | 100 per document, 256 KiB sidecar, 4,000-character quote and 2,000-character note |

Page/frame dimensions also have an 8,192-pixel axis limit. Preview fetches start
when visible and transfers are serialized to respect the paired request budget.
Leaving the chat, disconnecting or revoking access stops the preview and its
outstanding transfer. Reconnect reloads persisted notes and leaves animations
paused. New snapshot/sidecar suffixes are ignored by the a2.5 pruner, preserving
them through rollback; the current release removes them with the owning chat.

PDF.js **6.5.438** is the official Mozilla `pdfjs-dist` distribution under
Apache-2.0. `npm run prepare:media` verifies the pinned npm tarball SHA-512 and
records SHA-256 hashes for 203 bundled decoder/font/license files. Package
verification checks those hashes; the application does not download preview
code at runtime. See the [PDF.js project](https://github.com/mozilla/pdf.js) and
[official distribution guide](https://mozilla.github.io/pdf.js/getting_started/).
Its licenses and required font notices are retained in `renderer/vendor/pdfjs`.

## Observed source checks

The seven focused suites passed **50 tests**. Source syntax, asset integrity and
privacy checks passed. The real Electron `--smoke-media` fixture used the normal
renderer, bridge, publication store, preview protocol and decoder assets, plus
the real encrypted relay on loopback. No model provider was called.

The fixture observed:

- Actual two-page PDF canvas painting, text selection, page navigation, zoom,
  saved highlights/notes and a readable translucent selection/highlight overlay.
- A real DOCX ZIP containing explicit page breaks, repeated text, a 2×2 table
  and an embedded DrawingML picture. The preview displayed the reflow notice,
  every labeled cell and the graphic placeholder. A highlight on the second
  occurrence remained on that occurrence.
- Decoded SVG image pan/zoom, with script/foreignObject/external-resource input.
- Different actual decoded pixels for two GIF/APNG frames, play/pause and frame
  stepping, including APNG data named `.png`.
- All six previews and byte-identical original saves in local and paired UI,
  using 41 authenticated media reads. Reconnect restored notes and kept animation
  paused; device revocation rejected further bytes and annotation access.
- Malformed DOCX entity rejection. Actual child-frame fetches to arbitrary
  preview paths, the parent app origin and an external origin were denied.

The native file chooser and clipboard writers were intercepted in the isolated
fixture; no user clipboard or active profile was changed. Source regressions
also cover immutable bytes/revisions, annotation ownership/idempotency/restart,
archived/aborted writes, bounded sidecar allocation, ZIP expansion limits,
protocol allowlisting and the earlier-release pruning rule.

`runInstalledSmoke` includes the same bounded local preview fixture for a2.6
and later. It needs no relay source or provider connection, and checks packaged
assets, frame isolation, page/animation controls, notes and original saves.
Earlier-version installer smoke remains compatible. Its fixture retains media
bytes and notes for upgrade/rollback verification on subsequent a2.6 runs.

Physical two-PC/WAN acceptance remains pending. DOCX text reflow does not claim
Word-exact layout, OCR, embedded media playback or editing of original files.
Additional codecs, arbitrary-document corpus coverage and maximum-size decoding
stress are outside this bounded fixture.
