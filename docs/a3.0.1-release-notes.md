# Faber a3.0.1

The Windows installer can now upgrade a2.4 profiles that predate background
jobs and routines. If a3.0 already stopped during its worker checkpoint,
close that setup window and run the full a3.0.1 installer over the existing
installation. The installer preserves the failed record and creates a fresh
checkpoint from the current profile.

Setup can reuse an intact checkpoint on retry. It checks for changed chats,
work receipts and worker ownership before proceeding. If it cannot safely
continue, the message identifies the problem and the next step. Background
jobs reopen paused for review. An older worker-enabled uninstaller may revoke
a before-sign-in grant during an upgrade. That grant requires fresh approval.

This release includes a new versioned workbench. The installer is unsigned.
The [a3.0 capability and acceptance limits](a3.0-release-notes.md) still apply.
