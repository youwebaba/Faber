# Faber a3.0.2

GGUF vision models can now start with their matching vision companion
(the projector GGUF that connects images to the language model).

When browsing a compatible model, **Vision companion** selects the matching
Q8_0 projector by default. F16 is available when the repository provides it.
Choose **Text only — no companion** to download only the language model.

For an existing download, open **Models → Downloads & library**, select the
model and choose **Add or update vision companion**. **Download vision
companion only** fetches the matching file from the original repository revision
into the model's folder without downloading its main weights again. Stop and
start the local model to use the completed pair.

The local picker shows the selected companion before Start. Startup uses local
files only. Incomplete, linked, unrelated or ambiguous projectors are not loaded.
A model without a complete matching companion stays text only.

Local GPU verification passed with Qwen3.5-9B-Kimi-k3-Distilled Q3_K_M and its
matching Q8_0 companion, including real image input and text chat. The companion
download used the publisher's pinned revision and verified SHA-256. Other model
and hardware combinations remain separately qualified.
This release includes a new versioned workbench. The installer is unsigned.
The [a3.0 capability and acceptance limits](a3.0-release-notes.md) still apply.
